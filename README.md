# synOTR

SynOTR liefert einen Workflow für TV-Aufnahmen von onlineTVrecorder (OTR) auf Synology NAS. 

synOTR übernimmt 
- decodieren 
- AC3-muxing (BETA) 
- schneiden 
- MP4-Konvertierung 
- Umbenennung 

## Installation:
- benutze bitte das fertige und signierte Paket von [cphub.net](https://www.cphub.net/?id=37)
- um ein eigenes SPK aus dem aktuellen master-branch zu bauen, nutze das Buildskript: build_spk.sh
